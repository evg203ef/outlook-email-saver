# Portfolio notes

## What the original project demonstrated

- Python application development
- Windows desktop automation
- Outlook COM/MAPI integration via pywin32
- File and directory handling
- Filtering and batch processing
- Attachment export
- Error logging and recovery at item level
- Iterative development with AI coding assistants

## Accuracy notes for the job application

The source project does not currently demonstrate web scraping, Playwright, REST API integration, databases, or production Git workflows. Those should not be claimed as capabilities of this repository.

The strongest concrete claim supported by the code is that it is a working personal automation project for exporting Outlook messages and attachments from a local Windows Outlook profile.
